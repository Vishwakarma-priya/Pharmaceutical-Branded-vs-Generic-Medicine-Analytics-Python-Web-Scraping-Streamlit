💊 **Pharmaceutical Branded vs Generic Medicine Analytics | Python + Web Scraping + Streamlit**

Built an end-to-end pharmaceutical data analytics project using **real-world medicine data collected directly from verified e-pharmacy and official retail sources**.

🔹 **Key Highlights:**
• Developed a Python-based **web scraping/API data collection pipeline**
• Collected and cleaned **branded and generic medicine datasets**
• Extracted medicine names, salt compositions, manufacturers, packaging, MRP/prices, therapeutic groups, and side-effect information
• Performed **data cleaning, validation, and transformation using Pandas**
• Analyzed **price differences between branded and generic medicines** across therapeutic categories
• Identified **top pharmaceutical manufacturers and medicine categories**
• Built an interactive **Streamlit dashboard** for data exploration and visualization
• Prepared an evidence-based report documenting the **data collection methodology and source verification**

🛠️ **Tools & Technologies:**
Python | Pandas | Web Scraping | API | Streamlit | Data Cleaning | Data Analysis | Data Visualization | CSV | GitHub

📌 **End-to-End Workflow:**
**Data Collection → Data Cleaning → Data Validation → Analysis → Streamlit Dashboard → Insights**

This project strengthened my practical skills in **Python, web data collection, data analytics, and dashboard development** while working with a real-world pharmaceutical use case.
